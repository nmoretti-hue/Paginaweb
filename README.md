Portfolio de Nico Moretti

Este proyecto es un portfolio personal hecho con HTML y CSS. Presenta
informacion sobre mi, mis habilidades y mis proyectos: Juego del
Calamar, Pokemon y Reproductor de musica. Tambien incluye navegacion,
imagenes, carruseles, favicon y modo oscuro.

Bitacora

Investigue HTML y etiquetas semanticas en W3Schools. Luego aprendi
CSS, Flexbox, Grid, efectos `hover`, Bootstrap, fuentes, favicon y
media queries para adaptar la pagina a celulares.
